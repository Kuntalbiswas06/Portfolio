## ◈ About This Project

This isn't just another developer portfolio. It's an interactive digital experience designed to showcase my development journey, technical skills, and projects.

The centerpiece is a **3D particle portrait generated from my real photograph**, combined with cinematic animations and smooth scrolling to create an immersive browsing experience.

### ✦ Experience Highlights

- 🧬 **Interactive Particle Portrait** — Real photograph transformed into thousands of animated particles using Three.js.
- 🎬 **Cinematic Animations** — Scroll-triggered animations powered by GSAP.
- 🌀 **Smooth Scrolling** — Fluid navigation using Lenis.
- 🖱️ **Interactive Elements** — Custom cursor, magnetic interactions, and dynamic effects.
- 📱 **Responsive Experience** — Optimized for desktop, tablet, and mobile.
- ⚡ **Performance Optimized** — Adaptive particle density and rendering.
- ♿ **Accessibility** — Reduced-motion support and WebGL fallback.

## ◈ Run Locally

```bash
# Clone the repository
git clone https://github.com/Kuntalbiswas06/Portfolio.git

# Navigate into the project
cd Portfolio

# Start the development server
npm run dev
```

Open `http://localhost:5173` in your browser.

Alternatively, without Node.js:

```bash
python3 -m http.server 5173
```
